# DiceGames
Projekt 1 – Tärningsspel: Ett Java‑projekt av Phatchari och Cajsa Lermark där vi bygger ett textbaserat tärningsspel med klasserna Die, Player och DiceGame. Spelet låter spelaren gissa tärningsvärden, samla poäng och spela valfritt antal omgångar. Fokus ligger på OOP, testning, Git och tydlig kodstruktur.
