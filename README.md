# DiceGame

Ett Java‑projekt av Phatchari, Cajsa Lermark och Damian Dzafic där vi bygger ett textbaserat tärningsspel med klasserna Die, Player och DiceGame. Spelet låter spelaren gissa tärningsvärden, samla poäng och spela valfritt antal omgångar. Fokus ligger på OOP, testning, Git och tydlig kodstruktur.
